# React Job Listing Cards

📌 Description

This is a beginner-friendly React project that demonstrates the use of reusable components and props. It displays multiple job listing cards with different data using a single component structure.

🚀Tech Stack
* React.js
* CSS

🎯Features
* Reusable card component
* Props used to pass dynamic data
* Clean and simple UI design

📚 What I Learned
* How to create and reuse components in React
* How to use props to pass data between components
* Basic UI structuring with CSS

⚙️Installation
1. Clone the repository
2. Run `npm install`
3. Run `npm start`
